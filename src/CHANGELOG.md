## [0.1.0] - 2026-03-09

### Added
- Initial ROS2 Humble workspace for Manriix autonomous photography robot
- ZED X front/left/right camera integration via GMSL2
- ground_segmentation_ros2 integration tuned for ZED X point clouds
- RPLidar A2M12 sensor driver
- 4-wheel steering controller (manriix_4ws_controller)
- Robot description package (manriix_description) with URDF/xacro
- EKF localisation node
- ROS bridge websocket server
- Gimbal controller for DJI RS3 Pro
