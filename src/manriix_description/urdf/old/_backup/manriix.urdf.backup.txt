<!-- ### Understanding ros2_control in URDF:
```
┌─────────────────────────────────────────────────────────────────────────┐
│                    ros2_control BLOCK                                   │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  <ros2_control name="manriix_control" type="system">                    │
│                 ▲                      ▲                                │
│                 │                      └── Type: system (multi-joint)   │
│                 └── Name for this hardware interface                    │
│                                                                         │
│    <hardware>                                                           │
│      <plugin>mock_components/GenericSystem</plugin>                     │
│              ▲                                                          │
│              └── Fake hardware for testing                              │
│                  (Later: replace with real hardware plugin)             │
│    </hardware>                                                          │
│                                                                         │
│    <joint name="steering_front_left_joint">                             │
│                 ▲                                                       │
│                 └── MUST match joint name in URDF!                      │
│                                                                         │
│      <command_interface name="position">                                │
│                              ▲                                          │
│                              └── We SEND position commands              │
│                                                                         │
│      <state_interface name="position"/>                                 │
│                            ▲                                            │
│                            └── We READ position feedback                │
│                                                                         │
│    </joint>                                                             │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘ -->
<!-- ### Hardware Plugin Options:

| Plugin | Use Case |
| `mock_components/GenericSystem` | Testing without real hardware |
| `gazebo_ros2_control/GazeboSystem` | Gazebo simulation |
| `gz_ros2_control/GazeboSimSystem` | Ignition Gazebo simulation |
| Custom plugin | Real hardware | -->
```
